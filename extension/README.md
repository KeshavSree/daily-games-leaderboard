# Daily/

Chrome and Edge extension for MapTap, Chainle, Krillion, and English Linkdle.

1. Unzip this folder.
2. Open chrome://extensions (Edge: edge://extensions).
3. Enable Developer mode, choose Load unpacked, and select this folder.
4. Log in at https://daily-games-leaderboard.vercel.app in the same browser.
5. Reload any game tabs that were already open when the extension was installed.
6. Finish a game. Click Submit to Daily on the detected result. If it is not detected, use the game's Share/Copy result button, then click Submit to Daily.

The toolbar popup also shows the detected result. Submissions are permanent; the extension never submits without a click. Existing score validation, same-day matching, Linkdle word-pair matching, and overnight Elo settlement apply.

The extension reads visible result text and observes share text generated by these four sites. It does not read your clipboard, browser history, passwords, or authentication cookies. An inactive Daily extension tab handles requests with your existing Daily session; keep it open or it will be reopened on the next submission. The extension receives the submission outcome, never session credentials. No analytics or external services are used.

The release is unpacked, not a Chrome Web Store listing. Website layout changes can affect detection. Share text has no cryptographic verification; the existing honor system still applies. Safari and Firefox are not included.
